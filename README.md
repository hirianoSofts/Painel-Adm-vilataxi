# VilaTáxi Admin Dashboard

Dashboard administrativo responsivo para a plataforma VilaTáxi.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos e responsividade
- `js/app.js` — navegação e interações
- `assets/vilataxi-logo.png` — logótipo fornecido

## Tecnologias

- HTML5
- CSS3
- JavaScript vanilla
- Poppins (Google Fonts)
- Hugeicons Stroke Rounded via CDN

## Executar

Abra `index.html` no navegador. Não precisa de servidor para o protótipo visual.

## Observação

Os dados apresentados são dados demonstrativos. Para produção, substitua-os por dados vindos da API/Firebase e implemente autenticação, permissões e operações reais.
